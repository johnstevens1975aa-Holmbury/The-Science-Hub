Practical investigation support

Investigation routine

  1. Identify independent, dependent and control variables.
  2. Write a reproducible method.
  3. Record results with units.
  4. Calculate means and identify anomalies.
  5. Evaluate reliability and improvements.

Student write-up frame

Prediction → apparatus → method → results → graph → conclusion → evaluation → improvement.

Common practical mistakes

Missing units, vague method, no repeats, no control variables, and conclusions not linked to evidence.

Key definitions

Independent variable

The factor deliberately changed by the investigator.

Dependent variable

The factor measured to see the effect of the independent variable.

Control variable

A factor kept the same so the investigation is fair.

Accuracy

How close a measurement is to the true value.

Reliability

How consistent results are when repeated.
